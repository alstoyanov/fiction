# Personal Albums

Albums that are **not based on any mythology**: personal, philosophical or autobiographical concept albums. They sit outside the mythology cycle, so they are free to use a **different sound** from the band's power, heavy and symphonic default. Each album sets its own sound in its README.

## Folder Structure
Personal albums use the normal album template (`_templates/album/`), with two changes:
- **`lore.md` becomes `concept.md`.** It holds the album's idea, arc, recurring motifs and voice, instead of a myth and its sources.
- **§1 of each track file is "Meaning Behind the Song"** instead of "Story Behind the Song": two to three paragraphs on what the song is about and where it sits in the album's arc.

```
personal/
├── README.md                  ← this file
└── <NN-album-slug>/           ← numbered in release order: 01-…, 02-…
    ├── README.md              ← concept, sound, tracklist, status, credits
    ├── concept.md             ← the idea, the arc, motifs, voice (replaces lore.md)
    ├── tracks/
    │   └── NN-track-slug.md   ← meaning · Suno style · Suno lyrics · cover prompt
    ├── art/
    │   └── cover-prompts.md
    └── release/
        └── release-notes.md
```

## Sound Rules
- **Each album sets its own base style** in its README. The band's default exclude list (`guides/suno.md`) is the starting point, and the album README says which items it lifts, and on which tracks.
- **Still never name real artists or bands in Suno.** Describe the sound. A reference artist can be noted in the album README for our own use only.
- **The house style still applies:** three verses per song (`guides/lyrics.md`), except where an interlude is deliberately short.
- **All lyrics are original.** A reference artist is a guide for the sound and the delivery, never for lines.
