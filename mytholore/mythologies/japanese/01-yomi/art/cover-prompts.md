# Yomi: The Land of the Dead: Album Cover Art

This file covers the **album** cover and its variants. Each song's art prompt is in its track file (§4). Every track prompt shares the cover's style line, so the set looks like one family.

**Concept:** Izanagi at the threshold of Yomi, holding up the single burning comb-tooth. Its small light reveals, deep in the dark, the vast seated silhouette of Izanami, crowned with the eight thunders. This is the moment just before the forbidden look.
**Mythology visual palette:** see `../../README.md` (ink black, vermilion, indigo, gold leaf; waves, serpents, mirrors, swords, magatama). **Avoid** the Rising Sun motif and shrine desecration.
**Final image:** `<file name>`. At least 3000×3000 px.

**Shared style line** (identical in every prompt for this album):
```
ukiyo-e woodblock print fused with sumi-e ink wash, black ink, vermilion and gold leaf accents
on aged washi paper, dramatic negative space, highly detailed, square format, no text, no lettering
```
